# Unit Conversion (C)

This program provides menu-driven conversions for temperature and time.

Build & run (PowerShell):
```powershell
cd c:\Projects\cardealership\UnitConversion
gcc -g UnitConversion.c -o UnitConversion.exe
.\UnitConversion.exe
```

Features:
- **Temperature**: Celsius ↔ Fahrenheit
- **Time**: 12-hour ↔ 24-hour format

Usage: follow the menu prompts to select conversion type and enter values.
