# Distance Conversion (C)

Menu-driven distance conversion program using switch-case.

Build & run (PowerShell):
```powershell
cd c:\Projects\cardealership\DistanceConversion
gcc -g DistanceConversion.c -o DistanceConversion.exe
.\DistanceConversion.exe
```

Conversions: Feet ↔ Meters, Miles ↔ Kilometers
