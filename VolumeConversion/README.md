# Volume Conversion (C)

Menu-driven volume conversion program using switch-case.

Build & run (PowerShell):
```powershell
cd c:\Projects\cardealership\VolumeConversion
gcc -g VolumeConversion.c -o VolumeConversion.exe
.\VolumeConversion.exe
```

Conversions: Gallons ↔ Liters, Liters ↔ Fluid Ounces
