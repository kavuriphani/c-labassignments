# Product Management System (C)

This program reads product details, computes total bill, GST and net bill according to product type.

Build & run (PowerShell):
```powershell
cd c:\Projects\cardealership\ProductManagement
gcc -g ProductManagement.c -o ProductManagement.exe
.\ProductManagement.exe
```

Usage: follow the prompts to enter product number, name, type (`E` or `M`), unit price and quantity.
