# Memory Conversion (C)

Menu-driven memory size conversion program using switch-case.

Build & run (PowerShell):
```powershell
cd c:\Projects\cardealership\MemoryConversion
gcc -g MemoryConversion.c -o MemoryConversion.exe
.\MemoryConversion.exe
```

Conversions: KB ↔ MB, MB ↔ GB, MB ↔ TB, GB ↔ TB
