# Employee Management System (C)

This program manages employee records with basic CRUD operations.

Build & run (PowerShell):
```powershell
cd c:\Projects\cardealership\EmployeeManagementSystem
gcc -g EmployeeManagementSystem.c -o EmployeeManagementSystem.exe
.\EmployeeManagementSystem.exe
```

Features: Store and manage employee details including ID, name, designation, salary.
