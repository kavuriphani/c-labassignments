# Electricity Bill Generator (C)

This program calculates and displays electricity bills based on units consumed.

Build & run (PowerShell):
```powershell
cd c:\Projects\cardealership\ElectricityBillGenerator
gcc -g ElectricityBillGenerator.c -o ElectricityBillGenerator.exe
.\ElectricityBillGenerator.exe
```

Features: Read consumer number, name, and units consumed; calculate bill with surcharge if applicable.
