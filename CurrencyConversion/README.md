# Currency Conversion (C)

This program performs currency conversions between INR, US Dollar, and Japan Yen using a switch-case menu.

Build & run (PowerShell):
```powershell
cd c:\Projects\cardealership\CurrencyConversion
gcc -g CurrencyConversion.c -o CurrencyConversion.exe
.\CurrencyConversion.exe
```

Exchange rates (approximate):
- 1 INR = 0.012 USD
- 1 USD = 83.33 INR
- 1 INR = 1.62 JPY
- 1 JPY = 0.617 INR

Usage: follow the menu prompts to select a conversion and enter the amount.
